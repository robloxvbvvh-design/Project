# Стук в отеле

Игра для Android (APK): стучишься в двери отеля, из номера выскакивает разъярённый
житель — и начинается погоня. Убежал — получил 50 💰 (и больше за прочные двери).
Прокачивай бег, выносливость, фору и жадность, покупай более прочные двери, разозли
все этажи отеля — даже директора. А если накопишь 1 000 000 💰 — тебя ждёт секретная концовка…

## Как получить APK
Каждый push запускает GitHub Actions (`.github/workflows/build-apk.yml`).
APK появляется в **Releases → apk-latest** и в артефактах запуска (Actions → Build APK).
Скачай `hotel-knock.apk` на телефон и установи (разреши установку из неизвестных источников).

## Запуск в браузере
Открой `www/index.html`.

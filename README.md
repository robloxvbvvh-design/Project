# 🎬 Студия Историй

Приложение: выбираешь одну из **37 историй** (зомби-апокалипсис, бандиты 90-х, блэкаут и др.) или вписываешь свою идею → настраиваешь **героя** (имя, возраст, профессия, характер, внешность, фраза) → выбираешь **голос** (11 характеров + системные голоса) → встроенный **агент** пишет сценарий, **промты для анимации** (по сцене) и **промт озвучки**, и тут же собирает **видео на HTML5 canvas с субтитрами, идущими по голосу**.

- Запуск: открыть `www/index.html` (всё в одном файле, работает офлайн, это PWA).
- Правки: редактируй `src/`, затем `python3 build.py`.
- Видео: «Смотреть», запись `.webm`, экспорт отдельного **HTML-видео** и проекта JSON.
- Агент: без ключа — встроенный генератор; с ключом Claude API (Настройки агента) сценарий пишет нейросеть.

## Собственный движок историй (`src/engine.js`)
Сценарий не берётся из готовых текстов-шаблонов, он **симулируется**:
1. **Онтология мира** — для каждого из 37 жанров заданы сущности: место, угроза, цель, предметы, препятствия, укрытие, союзник, знаки, тип сюжетного поворота.
2. **Состояние и планировщик** — здоровье героя, предметы, союзник, напряжение; действия (знак, завязка, решение, находка, путь, препятствие, погоня, союзник, неудача, поворот, финал) выбираются по условиям и кривой напряжения, число сцен 6/8/10.
3. **Реализатор языка** — морфология русского (6 падежей, род, число, одушевлённость, согласование прилагательных, прошедшее время, склонение имени героя) и синтаксис: предложения собираются из смысловых кадров «кто — что делает — с кем/чем — где».
4. **Визуал и промты** строятся из тех же событий (поза героя, дистанция угрозы, предметы, вспышки).
Каждый запуск — новый сюжет (seed показывается во вкладке «Агент»).

## APK
1. Автоматически: GitHub → Actions → **Build APK** → скачать артефакт `app-debug.apk`.
2. Вручную: `npm i @capacitor/core @capacitor/cli @capacitor/android && npx cap init Истории com.studio.istorii --web-dir=www && npx cap add android && npx cap sync && npx cap open android`.
3. Без сборки: открыть страницу в Chrome на телефоне → «Установить приложение» (PWA).

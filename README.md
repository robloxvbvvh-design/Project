# Super Keyboard

Клавиатура для Android (APK): 132 языка, эмодзи (тысячи + флаги + каомодзи), GIF, перевод, голосовой ввод.

Готовый APK: `dist/SuperKeyboard.apk`. Пересборка: `./build.sh` (нужны пакеты, перечисленные в скрипте).

## Установка
1. Установите APK (разрешите установку из неизвестных источников).
2. Откройте приложение → «Включить клавиатуру» → «Выбрать Super Keyboard».
3. Разрешение на микрофон запрашивается при первом запуске.
4. Для GIF вставьте бесплатный ключ Tenor API в настройках приложения.

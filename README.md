# Кинотеатр (Android APK)

Каталог: Декстер (все сезоны, Новая кровь, Воскрешение 1–2), Во все тяжкие, Backrooms (Kane Pixels), Animation vs Animator.
YouTube-сериалы воспроизводятся с YouTube внутри приложения. Для защищённых сериалов есть трейлеры и поле «Моя ссылка» (ваша легальная подписка).

## Сборка APK
GitHub → Actions → **Build APK** → артефакт `Kinoteatr-apk` (app-debug.apk). Запускается автоматически при push.
Локально: `gradle assembleDebug` (нужен Android SDK).
